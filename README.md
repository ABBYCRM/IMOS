# IMOS

Institutional site for IMOS — energy and fuel supply (EN590, jet fuel, diesel), infrastructure, and government and corporate relations.

The public site is a multi-page brochure:

- Home
- Energy and fuel
- Infrastructure
- Government and corporate relations
- Approach
- Commercial inquiry desk

The inquiry form prepares a numbered brief on the device. It does not send mail. Connect a mailbox before treating submissions as delivered.

## Run

```bash
npm run dev
```

The dev server listens on port 8080.
